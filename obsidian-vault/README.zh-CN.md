# Obsidian 知识库

在 Cindy 里找回你写过的笔记，也把值得留存的对话和待办写回 Obsidian。支持本机 Markdown 知识库，日常读写无需启动 Obsidian 或填写 API Key。

## 开始使用

1. 在 Cindy 桌面端打开侧栏的 **Obsidian 知识库**。已在这台电脑登记的 Obsidian 知识库会出现在列表里。
2. 如果找不到要用的库，点 **添加知识库**，选择存放笔记的根文件夹。这样会将它设为默认库。下拉列表只切换当前工作台。要更改聊天和 `@` 补全使用的默认库，可在插件详情的设置里修改。
3. 从 **浏览** 试着搜索笔记标题、正文或 `#项目/标签`。点开笔记后，可以在 **关联笔记** 里沿出链和反向链接继续浏览。

### 浏览目录和搜索

- 点击 **浏览目录** 逐级查看文件夹和笔记。要由 Cindy 枚举其他文件类型，可用 `list_notes` 指定相对目录、深度（1–10）和扩展名。
- 有更多搜索结果时，点击 **加载更多结果**。结果会标出第一个正文命中的行、列和上下文。只命中标题或属性的结果仍会出现。
- 搜索工具的 `nextCursor` 可原样传回 `cursor`。续页时保持查询、知识库、每页条数和命中上限一致。结果变化时从第一页重搜。

## 在对话里使用

- **引用笔记**。在输入框输入 `@`，用标题、路径或标签查找笔记。选择结果会插入引用，发送后 Cindy 可按引用读取原文。
- **保存一条回复**。在 AI 回复的正文视图切换器选择 **保存到 Obsidian**。表单会填入这条回复。核对目标知识库、相对路径和正文后再保存。默认存入 `Inbox/`，保存后可直接查看笔记，也可选择追加到已有笔记末尾或指定章节。
- **记录今天**。从输入框底部的 **Obsidian** 入口打开 **今日日记**。可以追加带时间的记录或添加复选框待办。第一次写入时按 Obsidian 的日记目录、日期格式和可读模板创建文件。
- **交给 Cindy 整理**。试试「`$obsidian` 帮我找到 `#项目` 下关于发布的笔记，列出原始路径」，或用 `/obsidian-capture` 把当前对话整理成笔记、用 `/obsidian-daily` 回顾或更新日记。也可以请 Cindy 查 Frontmatter、分析未连接提及，或整理 Canvas 白板。

## 从另一台电脑操作

- 在远程任务里发送「`$obsidian` 打开知识库工作台」。Cindy 支持远程任务卡片时，控制端可直接使用卡片。顶部显示知识库所在电脑的系统主机名。读写笔记和打开 Obsidian 都发生在该电脑。全局工作台使用打开入口对应的插件实例。
- 保存笔记或日记时如果断线，恢复后点 **检查保存结果**。查到回执会显示已保存的路径。当前表单仍保留原输入且未查到回执时，可以重试原请求。结果仍无法确认时，先核对目标笔记。Cindy 支持卡片状态保存时，重开原卡片也能接着查询。

## 精确编辑笔记

- 读取或修改重名章节时，传完整标题路径，例如 `headingPath: ["项目 A", "结论"]`。`read_note` 会返回每个标题的完整路径。
- 传笔记路径和 `blockId: "^summary"` 可定位块，也可直接读取 `[[计划#^summary]]`。修改块时会保留块 ID，遇到重复 ID 或无法安全定位的块会拒绝操作。
- `replace_in_note` 可在整篇正文、指定章节或块内做区分大小写的字面替换。先用 `dryRun: true` 核对匹配数，写入时可以传入预览返回的 `mtimeMs`，避免修改已经变化的笔记。

## 限定写入范围与整理标签

- 工作台的 **浏览 → 知识库写入规则** 按库设置。可以设为只读，或只允许写入 `Inbox`、`Daily` 等指定目录及其子目录。目录使用库内相对路径。限制模式下留空会拒绝所有写入。旧配置默认允许写入全库。
- 规则作用于本插件的笔记修改、回复入库、日记、Canvas 和移入回收站。搜索和读取仍可用。访问同一文件的重叠库也会应用已保存的限制。
- 用 `manage_tags` 列出、添加或移除笔记的 YAML Frontmatter 标签。匹配按完整标签名且忽略大小写。移除 `#项目` 会保留 `#项目/发布` 和正文中的 `#项目`。

## 文件与权限

- 插件的 Node 工作进程在执行电脑上读写已登记的知识库。新增的写入回执存于该电脑当前系统用户的应用数据目录，用于识别原请求。插件自身没有联网服务。让 Cindy 使用笔记回答问题时，读到的内容会进入你所选模型的任务上下文。
- 文件保存为普通 Markdown 或 `.canvas`。覆盖已有整篇笔记、整板替换或将笔记移入 `.trash` 前，Cindy 会显示目标并要求确认。
- 消息正文视图读取该条回复供你编辑。任务内打开的工作台可把引用插入草稿，发送仍由你触发。**在知识库所在电脑打开 Obsidian** 需要该电脑安装桌面端 Obsidian。

## 遇到问题

- **没有知识库**。在运行插件的电脑上用 **添加知识库** 选择实际文件夹。同名知识库会显示路径，便于区分。
- **找不到刚改过的笔记**。点 **刷新索引**。大型知识库可能只索引部分文件，工作台会提示。
- **新建时提示文件已存在**。更改相对路径，或确认目标后选择追加。保存失败时表单会保留。
- **工作台或 `@` 入口不可用**。检查插件是否启用、使用的是 Cindy 桌面端，以及知识库是否在运行插件的电脑上。也可以先试 `$obsidian` 点名调用。

支持 Cindy 0.1.143 或更新版本。Obsidian 桌面集成支持 1.15.1 或更新版本。反馈问题时请附 Cindy 版本、插件版本和复现步骤，提交前移除私人路径和笔记正文。
